# ShopLite

A shopping app built with Kotlin and Jetpack Compose, using the DummyJSON API.

## Features (planned)
- Login with token refresh
- Product grid with paging and search
- Product details, cart, favourites and checkout
- Works offline (Room cache)
- Price-drop notifications
- Order history
- Settings: dark mode and language

## Tech stack
Kotlin, Coroutines, Flow, Jetpack Compose, Material 3, MVVM, Hilt, Retrofit, Room, Paging 3, WorkManager
